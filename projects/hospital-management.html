Hospital Management System

A hospital management system with role-based access, live in production.

Spring BootReactMUIPostgreSQL
Live demo ↗

The problem

Clinics need one system to manage patients, staff, and records without paper.

What it does

  • Patient and staff records in one system.
  • Role-based access, so each staff member sees what their role needs.
  • Live in production.

How it's built

Spring Boot backend, React and MUI frontend, PostgreSQL database.
